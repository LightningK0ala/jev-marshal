# Contribute

1. Fork the repository.
2. Create a branch.
3. Run `npm ci`.
4. Make the change.
5. Run `npm run check`, `npm test`, and `npm run build`.
6. Open a pull request.

GitHub runs Jev Marshal against `jev-marshal.yml` on every pull request.

Do not commit API keys. Use `TYPESAFE_API_KEY` for live checks.
